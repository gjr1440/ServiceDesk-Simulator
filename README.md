# ServiceDesk-Simulator
Simulador online que encontrei e está me ajudando a aprender sobre a rotina de um help desk. 

Buscando me aperfeiçoar na área de Help Desk/Suporte Técnico, há mais ou menos 1 semana, encontrei um site muito bacana que resume o dia a dia na área de maneira simulada e simplificada (mas bem completa), possui:

-Sistema de Tickets com prioridades
-Simulação de chamadas com usuários 
-Sistema de Chat 
-FERRAMENTAS: Diretório (simula Active Directory com informações dos funcionários), Sala de Servidores (onde podemos acessar o estado dos servidores de uma empresa fictícia), Área de Trabalho Remota (onde podemos acessar máquinas dos usuários remotamente, simulando ferramentas como AnyDesk/TeamViewer e troubleshooting Windows 11), Implantação de Computador (onde podemos configurar máquinas - instalação de SO, domínio, etc), Prateleira de PCs (onde ficam armazenadas as máquinas já configuradas), Documentação (simula uma base de conhecimento, com explicação de resoluções, escalonamento, etc), Gestão de Ativos (mostra os dispositivos de cada funcionário) e Gerenciador de Envios (onde podemos enviar dispositivos para os funcionários/setores)

Observação: tanto no chat quanto nas chamadas (você pode falar por microfone), utilizam IA para simular os funcionários. 

Gratuitamente (a que estou usando), possui limite diário para ligações (1) e tickets (5); mas de forma paga ($ 20/mês = R$ 102,81/mês) é ilimitado, além de contar com outras funcionalidades bem chamativas: Mensagens de Voz (funcionários que não puderam ligar, enviam mensagens de voz por outro canal) e Entrevistas Simuladas (pra preparar pessoas que estão querendo se preparar para entrevistas na área). 

É uma ferramenta nova e bastante promissora, está me ajudando bastante e creio que poderá ser de muito proveito para outras pessoas que também desejam entrar nessa área.
